# Histórico Mensal - Junho 2026

### Inicialização do Projeto Memória & Cuidado

- **Decisão Técnica**: Definida a arquitetura usando Deno, React 19, Vite e TanStack Start; com um catálogo em JSON prevendo transição para banco NoSQL local.

### Setup Base e Estrutura de Rotas
- **O que foi feito**: Implementação do HomenagemProvider e todas as rotas do fluxo principal do Totem (/inicio, /catalogo, /painel, /instituicoes-escolha, /pagamento, /confirmacao).
- **Decisão Técnica**: Todo o estado da jornada ("Homenagem", "Fotos", "ONG") é local e limpo via Context API, garantindo segurança entre sessões e aderência à ausência de persistência remota.
- **Estado Atual**: Concluído.

### Motor Ambiental do Totem
- **O que foi feito**: Construção do Singleton de RequestAnimationFrame e sistema de camadas visuais para a tela inicial (/).
- **Decisão Técnica**: Desacoplamento da lógica de transição temporal do React state usando PRNG mulberry32 e injeção de CSS custom properties para evitar rendering engine lags.
- **Estado Atual**: Concluído.

### Auditoria de Segurança e Conformidade RCD (Junho 2026)
- **O que foi feito**: Execução de auditoria profissional identificando vulnerabilidades críticas, violações de arquitetura (RCD) e defeitos de usabilidade no Painel Administrativo.
- **Resoluções (SEC)**: Remoção de credencial hardcoded, inclusão de `verifyAdminAuth()` na gestão de mensagens (POST/PUT/DELETE) e prevenção contra vazamento de metadados do master. `JWT_SECRET` forçado em produção.
- **Resoluções (RCD)**: Paleta de cores, limites numéricos (maxLength 150) e mensagens extraídas do React e movidas para a camada Config (`admin-theme.ts`, `config.ts`, `strings.ts`). O Master User passou a utilizar variável de ambiente.
- **Resoluções (UX/INT)**: Instalação do `react-hot-toast` substituindo `alert()` nativo para feedback elegante no painel. Tipagem rígida de `any[]` com mapeamentos Prisma. Rota de limpeza de banco restrita a GESTORES. APIs públicas devidamente filtradas para não enviar registros nativos (`ativo: false`). Log de ações do sistema (`logAction`) integrado a todas as instâncias de mutação crítica.
- **Estado Atual**: Concluído e verificado.
